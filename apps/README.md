Пока пусто — первым сюда переедет IT Assets (Phase/Stage F), после того

(Stage A–E) и core/audit будет реализован.

`src/`, `migrations/`, `assets/brand/` (неизменяемый vendor-лого, см.
core/branding) и `tests/`.
