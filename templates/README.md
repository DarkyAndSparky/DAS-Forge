Заготовки новых приложений на ядре DAS-Forge.

| Шаблон | Что это |
|---|---|
| [`app/`](app/README.md) | минимальное, но настоящее приложение: вход, смена временного пароля, права, пример данных с API и страницей, админ-панель, CLI, миграции, резервные копии, алерты, переводы ru/en, тесты |

Описание и порядок работы — `docs/guide/09-workshop.md`, раздел «Шаблон приложения».
