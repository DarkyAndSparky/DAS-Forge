## 5. Читалка и запись xlsx: что не хватает
Сверено с кодом `packages/core/src/xlsx/` (0.1.408). Читатель возвращает только значения: `{ sheets: [{ name, hidden, rows, merges, tables }], warnings }`. **Писатель умеет больше, чем читатель** — ссылки, формулы, проверки данных, имена, свойства книги, закрепление областей, автофильтр записываются, но обратно не читаются.

| № | Чего нет в читателе | Зачем | Размер |
|---|---|---|---|
| X8 | Форматированный текст внутри ячейки (какие слова жирным, ссылки в тексте); условное форматирование. Перечень рисунков и диаграмм сделан в 0.1.413 | полнота сводки о файле | малый |
| X9 | Одинаковый результат для xlsx, xlsb, xls, ods по пунктам X1–X8 (где формат позволяет) | единый API `readSpreadsheet` | большой |
| X11 | Предел 20 000 строк по умолчанию в `readWorkbook`; потоковое чтение только для xlsx | большие выгрузки | средний |
| X12 | Писатель: оформление ячеек, условное форматирование, несколько таблиц, картинки | обратная симметрия с читателем | большой |

Сделано: X1, X10 (0.1.410), X2–X5 (0.1.412), X6, X7 и перечень рисунков из X8 (0.1.413). Порядок дальше: X9 и X12, остаток X8 по желанию.
