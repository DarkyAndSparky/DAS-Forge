Требует внимания при разработке

  1. Переводы. Словари ядра (оболочка, админка, учётные записи, тексты политик, каталог ошибок) переведены на i18next; приложения переопределяют отдельные тексты через texts. Третий язык требует изменений ядра: регулярное выражение в localeMiddleware, CHECK в policy_texts, флаги.
  2. Тема и язык выбираются на странице «Аккаунт» и хранятся в браузере (localStorage, cookie); хранения в учётной записи на сервере нет.
  3. Портирование приложений (apps/): этап приостановлен, apps/README.md отражает прежний план.
  4. Проверки, выполняемые только у владельца: полный npm test, npm run test:template, e2e, страницы режима обслуживания, входа и учётной записи в браузере, перевод времени в других часовых поясах. В среде разработки нет доступа к реестру npm.
  5. Docker описан и проверен чтением; первая сборка — реальная проверка.
  6. Открытые находки аудита: см. docs/audit-findings.md.
  7. Сборщик документации (scripts/build-docs.mjs) использует собственный конвертер Markdown; ссылки на .md превращаются в переходы внутри страницы или в страницы docs/pages/*.html. Значки shields.io и skill-icons подгружаются из интернета.

Правила, чтобы пробелы не возвращались

Новый модуль или опция — строка в соответствующем разделе, пример с путём к файлу workshop, тест; версия фичи в руководство не пишется.
