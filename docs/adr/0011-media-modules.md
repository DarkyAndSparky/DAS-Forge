# 0011. Модули звука и видео и внешняя программа ffmpeg

Статус: принято; пункты 1–3 реализованы в 0.1.303, пункты 4–5 (фоновая обработка, внешние хранилища) ждут первого приложения
Дата: 2026-11-13

## Контекст
Звук и видео в ядре отсутствуют. Владелец согласен с разделением: ядро даёт подключаемые модули, коннекторы и адаптеры; всё, что не нужно приложению, выключено по умолчанию; смысл (плеер, субтитры, звонки) остаётся приложениям.

## Решение
Отдельный подключаемый модуль `media`, по умолчанию выключен (`modules.media.enabled: false`), в реестре модулей, с записью в реестре обработки персональных данных (голос, лица).
1. **Приём и проверка** (`files`): тип по содержимому (mp4, webm, mkv, mp3, ogg, wav, m4a), лимиты размера и длительности, квоты, отдельный путь хранения вне базы.
2. **Раздача с Range (HTTP 206)**: проверка прав на каждый запрос, `Content-Type`, `nosniff`, `Accept-Ranges`, кэш.
3. **Адаптер `ffprobe`/`ffmpeg`** (внешняя программа, не npm-пакет): запуск без оболочки, массив аргументов, таймаут, лимит памяти и вывода, путь из конфигурации; без программы модуль работает без метаданных и перекодирования, `doctor` показывает «не найдена».
4. **Фоновая обработка** (превью-кадр, перекодирование, нормализация звука) через очередь с прогрессом; обязательный потолок размера и времени.
5. **Коннекторы** хранилищ (локальный диск; позднее S3-совместимое) за одним контрактом.

## Вне ядра
Плеер и интерфейс, субтитры, расшифровка речи, звонки и трансляции (WebRTC).

## Последствия и риски
`ffmpeg` ставится отдельно; лицензия зависит от сборки (LGPL или GPL), нужна подпись владельца, как для `sharp`/libvips. Видео занимает гигабайты: нужны квоты и срок хранения. Записи с голосом и лицом это персональные данные: срок хранения, журнал просмотров, удаление.

## Выкатка и откат
Модуль выключен по умолчанию; включение опцией. Откат: выключить, файлы остаются на диске.
