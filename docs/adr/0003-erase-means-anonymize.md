# 0003. Стирание пользователя по умолчанию обезличивает

Статус: принято
Дата: 2026-10 (модуль privacy)

## Контекст
Пользователь имеет право на стирание данных, но `audit_log` нельзя изменять, а удаление строки пользователя оставило бы журнал с висящими ссылками.

## Решение
`eraseUserData` по умолчанию обезличивает (anonymize): личные поля очищаются, запись остаётся. Удаление (`delete`) возможно только по явному режиму.

## Альтернативы
Всегда удалять: теряется связность журнала. Всегда обезличивать без выбора: не покрывает случаи, когда удалить нужно именно строку.

## Последствия
Безопасный выбор по умолчанию, нужный режим указывается явно. Последнего администратора нельзя ни обезличить, ни удалить (проверка и действие в одной транзакции, G-04).

## Безопасность и эксплуатация
Действие пишется в аудит. В интерфейсе «Пользователи» оно требует подтверждения.

## Выкатка и откат
Необратимо для самих данных, обратимо как политика (режим выбирается при вызове).
