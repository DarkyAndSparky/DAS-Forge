# 0008. Порты 9xxx, весь обмен только по HTTPS

Статус: принято
Дата: 2026-10-25

## Контекст
Нескольким приложениям платформы нужно жить на одной машине без конфликтов портов, а обмен нужно защитить.

## Решение
HTTPS слушает на порту 9N02, обычный HTTP на 9N01 и только как обязательный редирект на HTTPS. Всё остальное идёт только по HTTPS. Нумерация: workshop 9002/9001, IT Assets 9102/9101, каждое следующее приложение на 100 больше.

## Альтернативы
Стандартные 80 и 443: конфликтуют на одной машине и требуют привилегий. Допускать HTTP: ослабляет защиту cookie и заголовков (HSTS).

## Последствия
Предсказуемая раздача портов; описано в руководстве по настройке (`docs/guide/03-configuration.md`).

## Безопасность и эксплуатация
Сертификаты перечитываются без перезапуска; самоподписанный создаётся для разработки.

## Выкатка и откат
Порты настраиваются в конфигурации приложения.
