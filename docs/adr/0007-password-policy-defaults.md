# 0007. Политика паролей по умолчанию: 12 знаков, без срока

Статус: принято
Дата: 2026-10-31

## Контекст
Профили NIST и ФСТЭК предлагают разные значения; нужен разумный общий минимум.

## Решение
Минимальная длина 12 знаков для всех профилей, срок действия пароля по умолчанию не ограничен. Политика настраивается в админке; для администраторов можно задать свой минимум. Требования для мобильных устройств (приложения для инвентаризации ТМЦ) отложены до появления мобильных приложений.

## Альтернативы
Короткий минимум и обязательная смена по сроку: давно не рекомендуется NIST и раздражает пользователей. Разные минимумы по профилям: усложняет объяснение пользователю.

## Последствия
Одно правило для всех. Смену пароля по срокам можно включить настройкой. Две вкладки администратора не затирают политику друг друга (защита от потерянной правки, G-03).

## Безопасность и эксплуатация
Пароли хранятся как argon2id; при смене действует история паролей.

## Выкатка и откат
Значения по умолчанию в схеме настроек; меняются в админке.
